## S3 Bucket Encryption

- Configured server-side encryption for the S3 bucket.
- Encryption algorithm: AES256 (SSE-S3).
- Bucket Key: Enabled.
- SSE-C encryption: Blocked.
- Verified encryption using AWS CLI.

Command used:
aws s3api get-bucket-encryption --bucket codomax
